# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Apple Native
- **Notes:** Generous spacing, unified radii, fluid but restrained transitions. Mobile-first (users mostly open links from Zalo/Messenger). Existing dark "sơn mài" palette (gold #d97706, lotus #e11d48, jade #059669) stays as brand color, but new work leans toward calmer, neutral surfaces with color used for meaning (receive = green, owe = red, primary action = gold).

## Banned anti-aesthetics

- Gratuitous glassmorphism / `backdrop-filter` without a high-contrast boundary. Allowed: Apple-style material only with a visible 1px border and text meeting AA contrast.
- Floating pastel pill badges for ordinary metadata
- Arbitrary decorative gradients and neon glowing borders. Allowed: one gradient on the single primary action per screen.
- Multi-color radial rainbow gradients on standard CTAs
- Cartoon empty-state illustrations (people waving / high-fiving)
- Nested scrollbars and icon bloat inside inputs

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** ≥ 4.5:1 for normal text, ≥ 3:1 for large text, borders, and input boundaries. Muted grey text on the dark background must still pass 4.5:1.
- **Touch / focus:** Targets ≥ 44×44px (watch the small icon buttons in member rows). Visible focus ring on every interactive element; never `outline: none` without a replacement.

## Brand tone and microcopy voice

- **Voice:** Utilitarian & Minimal
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** UI language is Vietnamese. Short, precise, neutral; no jokes or slang ("đồng bọn", "sớ nợ", "Cam-pu-chia") in new copy. Money messages state the exact amount and who owes whom. Errors say what happened and what to do next.

## Icon library

- **Library:** Project SVG (Lucide style)
- **Package / path:** Inline `<svg>` in `index.html` / `trip.html`, 24×24 viewBox, stroke 2, round caps/joins, classes `.icon` / `.icon-sm`
- **Notes:** Copy new paths from Lucide so the set stays consistent. No other icon sets. No emoji as UI icons (existing 🧳 📸 💰 👥 🧾 should be replaced with SVG when those areas are touched).

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
